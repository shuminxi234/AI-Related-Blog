## 欢迎

这是 **AI Related Blog** 的第一篇文章。

### 博客定位

本博客聚焦于 AI 领域的技术实践与思考，内容包括但不限于：

- 🤖 **AI Agent** — 智能体架构、多智能体协作、工具使用
- 🧠 **LLM 应用** — Prompt Engineering、RAG、Fine-tuning、推理优化
- ⚙️ **自动化工程实践** — CI/CD、DevOps、AI 辅助开发
- 📝 **技术思考** — 行业观察、技术选型、经验总结

### 技术栈

- **框架**: [Hugo](https://gohugo.io/) + [PaperMod](https://github.com/adityatelange/hugo-PaperMod) 主题
- **托管**: GitHub Pages
- **写作**: Markdown，frontmatter 包含 title/date/tags/author

### 写作流程

博客采用多智能体协作流水线：
1. **选题编辑** → 从热点和技术趋势中筛选主题
2. **研究员** → 深度调研与资料整理
3. **撰稿人** → 撰写 2000 字左右的深度文章
4. **审核人** → 技术审查与润色
5. **发布者** → 推送至 GitHub Pages

期待在这里分享有价值的技术内容 🚀
